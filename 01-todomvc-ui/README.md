# TodoMVC UI 测试

## 被测项目

本地被测源码建议放在：

```text
D:\qa-automation-targets\todomvc
```

来源：[tastejs/todomvc](https://github.com/tastejs/todomvc)

先按 TodoMVC 项目 README 启动一个本地页面，再配置测试使用的 URL。不要把 TodoMVC 源码复制到本目录；本目录只保存 Playwright/Pytest 等测试代码、配置和少量必要证据。

## 学习重点

- 元素定位与稳定断言
- 新增、完成、删除 Todo
- Active、Completed、All 筛选
- 参数化和失败证据
