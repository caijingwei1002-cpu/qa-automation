## 学习记录

今天理解了：购物车徽标证明外部数量提示，`.cart_item` 数量证明购物车内部实际内容，商品名称证明身份，价格证明业务数据一致；独立 Browser Context 保证数量从干净状态开始。

它解决的问题：防止测试只证明“加了一个”却不知道“加的是谁”，也防止列表页和购物车页同时错误但因为互相复制实际值而假通过。

我实际如何使用它：在 `test_cart.py` 中先使用独立预期名称和价格验证 Backpack 商品卡片，再在卡片内部点击 `Add to cart`；验证徽标为 1，进入购物车后验证 URL、标题、唯一商品项、名称和价格。

遇到的问题：测试没有业务断言失败，也没有环境阻塞。收尾前发现目标文件的 Git 暂存版本为空，而完整实现位于工作区。

根因或当前假设：空暂存版本是此前遗留状态，不影响 pytest 使用工作区完整文件执行；提交前需要显式暂存完整文件，避免提交空版本。
