## 学习记录

今天理解了：pytest 负责发现和组织测试，Playwright 负责浏览器交互，expect 负责等待并断言页面状态。页面初始化由 conftest.py 中的 todo_page fixture 完成。

它解决的问题：把手工操作转成可重复执行的 UI 检查，并用用户可观察的业务结果证明功能确实生效。

我实际如何使用它：在 test_add_todo 中通过 locator 找到输入框，填入 Buy milk 并按下 Enter，再使用 expect 验证列表数量、文本和未完成计数。

遇到的问题：第一次执行时 pytest 找不到 test_add_todo 节点；第二次执行时本地页面返回 ERR_CONNECTION_REFUSED。

根因或当前假设：Day 1 测试最初是类方法，和计划要求的模块级节点不一致；执行测试时 Python HTTP 服务没有运行。前者通过调整测试结构和移除 self 修复，后者通过重启并保持 8080 服务运行修复。
