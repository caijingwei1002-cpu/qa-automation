# Restful Booker API 测试

## 被测项目

本地被测源码建议放在：

```text
D:\qa-automation-targets\restful-booker
```

来源：[mwinteringham/restful-booker](https://github.com/mwinteringham/restful-booker)

按被测项目 README 使用 npm 或 Docker 启动本地 API。测试代码通过环境变量读取服务地址，不要把第三方服务源码放进本目录。

## 学习重点

- 健康检查和 CRUD
- Token 鉴权
- 接口之间的数据关联
- Schema 校验、数据隔离和清理
